¿Qué es la Lógica de Programación?

La lógica de programación es la habilidad de pensar paso a paso para resolver un problema. Antes de escribir código en lenguajes como Python, JavaScript o C++, necesitas saber qué instrucciones darle a la computadora y en qué orden.

El concepto Booleano (Verdadero o Falso)

En el corazón de las computadoras, todo se reduce a dos estados: 1 (Verdadero / Encendido) y 0 (Falso / Apagado). Toda decisión que toma una máquina se basa en estas dos opciones.

Operadores Lógicos

En programación, usamos operadores lógicos para combinar condiciones y tomar decisiones.

AND (Y)

&&

Devuelve Verdadero SOLO SI AMBAS condiciones son verdaderas.

if (tengo_dinero && tengo_tiempo) {
  // Voy al cine
}

OR (O)

||

Devuelve Verdadero si AL MENOS UNA condición es verdadera.

if (llueve || hace_frio) {
  // Llevo abrigo
}

NOT (NO)

!

INVIERTE el valor. Lo verdadero se vuelve falso, y viceversa.

if (!estoy_cansado) {
  // Sigo estudiando
}

Compuertas Lógicas

Son los componentes electrónicos físicos dentro de los procesadores que implementan las operaciones lógicas.

Compuerta AND

La salida es 1 (Alta) solo si ambas entradas son 1.

Compuerta OR

La salida es 1 (Alta) si al menos una entrada es 1.

Compuerta NOT (Inversor)

Tiene una sola entrada. Su salida es el inverso de la entrada (1 pasa a 0, y 0 a 1).

Tablas de Verdad

Una tabla de verdad es un mapa que muestra todos los escenarios posibles de entrada (0 y 1) y cuál será el resultado exacto de la compuerta lógica. ¡Es la herramienta definitiva para predecir cómo actuará tu código!
